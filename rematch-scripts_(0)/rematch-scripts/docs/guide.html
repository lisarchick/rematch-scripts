Как всё устроено

Своего сервера нет и покупать ничего не надо. Библиотека лежит в твоём репозитории на GitHub, приложение читает её оттуда.

ЧтоКому нужноЗачем
Rematch Scripts.exeвсемсамо приложение (каталог, меню, оверлей)
Python 3.10+ (python.org, галочка Add python.exe to PATH)всем, кто запускает скриптыскрипты написаны на Python. Ставится один раз
Библиотеки Python (opencv, mss и др.)—ставятся сами при первом включении скрипта
Драйвер ViGEmBusтолько для режима «Геймпад»виртуальный геймпад. Ставится один раз
GitHub-токентолько тебе (владельцу)чтобы загружать скрипты. Остальным не нужен
Загружать скрипты можешь только тыКнопка «Загрузить свой» появляется в приложении только если токен принадлежит владельцу репозитория. У всех остальных её нет, а изменить репозиторий они не могут.

1. Заливаем проект на GitHub один раз

  • Создай репозиторий

    Открой github.com/new. Имя rematch-scripts, тип Public, нажми Create repository.

  • Загрузи файлы

    Распакуй rematch-scripts.zip. На странице репозитория нажми uploading an existing file, нажми Ctrl+A в папке проекта и перетащи всё в окно браузера (важно, чтобы загрузилась и скрытая папка .github; если её не видно, включи в Проводнике «Показать скрытые элементы»). Внизу Commit changes. Если GitHub ругается на количество файлов, залей в два приёма.

  • Впиши свой ник

    Открой config.json → карандаш → замени YOUR_GITHUB_USERNAME на свой ник → Commit changes. То же в README.md (там ник в плашке скачивания).

  • Разреши автоматике писать

    Settings → Actions → General → Workflow permissions → Read and write permissions → Save. Без этого список скриптов не обновится.

  • Первый запуск списка скриптов

    Вкладка Actions → слева Build library index → Run workflow. Если такого запуска нет, внеси любую правку в папку library (например, залей скрипт через приложение, см. раздел 5). Должен появиться файл library/index.json.

  • Оформи страницу

    Справа шестерёнка у About: описание и темы. Settings → General → Social preview: загрузи assets/social-preview.png.

    Не включай «Require a pull request before merging»Загрузка из приложения записывает скрипт прямо в ветку main. Такое правило заблокирует тебя самого. Чужие люди и так не могут изменить твой репозиторий, они не участники.

2. Собираем приложение (.exe)

  • Запусти сборку

    Actions → Build Windows app → Run workflow. Через 3–5 минут появится зелёная галочка.

  • Выпусти релиз

    Справа на главной странице репозитория Releases → Create a new release → в Choose a tag впиши v1.0.0 → Create new tag → Publish release. Через несколько минут к релизу прикрепятся два файла:

    ФайлЧто это
    Rematch Scripts Setup 1.0.0.exeустановщик, делает ярлык в меню «Пуск»
    Rematch Scripts 1.0.0.exeportable: запускается сразу, без установки
  • Своя иконка

    Заменить файлы build/icon.png (1024×1024) и build/icon.ico в репозитории, затем выпустить новый релиз (v1.0.1).

3. Как открыть приложение

  • Скачай и запусти

    Репозиторий → Releases → скачай .exe → запусти. Этой же ссылкой делись с друзьями.

    Windows SmartScreenПриложение не подписано платным сертификатом. Если Windows пишет «Система защитила ваш компьютер», нажми Подробнее → Выполнить в любом случае.
  • Поставь Python

    Если ещё нет: python.org/downloads → установщик → галочка Add python.exe to PATH → Install. Приложение само подскажет, если Python не найден.

  • Язык

    Настройки → Язык интерфейса (Русский / English). Переводятся только надписи приложения, тексты скриптов остаются как их написал автор.

4. Как работают меню и оверлей

  • Скачать скрипт

    Все скрипты → открой нужный → Скачать и добавить в меню. Одна кнопка: приложение скачивает файлы и ставит скрипт в меню. Сейчас в библиотеке есть Rematch Ball Lock Pack (наведение на мяч).

  • Включить

    Вкладка Меню скриптов: у каждого скрипта тумблер. При первом включении приложение само докачает библиотеки Python (это занимает до минуты, статус «Установка библиотек…»). Потом статус станет «Работает» с зелёным индикатором.

  • Настроить

    Шестерёнка открывает настройки скрипта: ползунки, переключатели, списки. Изменения применяются сразу (если нужен перезапуск скрипта, приложение сделает это само). Для каждого скрипта можно задать свою клавишу вкл/выкл: нажми в поле и нужное сочетание. «Сбросить настройки» вернёт стандартные значения.

  • Оверлей поверх игры

    По умолчанию открывается и закрывается клавишей F10 (меняется в Настройках). Это то же меню, но маленьким окном справа поверх игры: можно включать скрипты и крутить настройки, не сворачивая игру. Закрыть: Esc, крестик или та же клавиша. Приложение должно быть запущено (можно свернуть).

Игра в режиме «Окно без рамки»Оверлей и захват экрана работают, когда Rematch запущен в Borderless / Окно без рамки. В «чистом» полноэкранном режиме окна поверх игры и захват экрана могут не работать.

5. Как ты загружаешь новые скрипты только владелец

  • Один раз: токен

    В приложении Настройки → Создать токен на GitHub → внизу страницы Generate token → скопируй токен (ghp_…) → вставь в поле → Сохранить. Появится вкладка Загрузить свой. Токен = пароль, никому не показывай, хранится зашифрованно.

  • Заполни форму

    Название, описание, инструкция, фото, файлы (zip и любые другие). Нажми Опубликовать: скрипт сразу записывается в репозиторий и появляется у всех (через минуту, нажми «Обновить»).

  • Чтобы скрипт был в меню с тумблером и настройками

    Заполни два дополнительных поля:

    • Файл запуска: имя главного .py файла среди загруженных (например my_script.py).
    • Настройки (JSON): список параметров, которые появятся в меню. Пример:
    [
 {"key":"speed","type":"number","label":{"ru":"Скорость","en":"Speed"},"min":1,"max":10,"step":1,"default":5},
 {"key":"debug","type":"bool","label":{"ru":"Отладка","en":"Debug"},"default":false},
 {"key":"mode","type":"select","label":{"ru":"Режим","en":"Mode"},"default":"a","restart":true,
  "options":[{"value":"a","label":{"ru":"А","en":"A"}},{"value":"b","label":{"ru":"Б","en":"B"}}]}
]

    Типы: number (ползунок), bool (переключатель), select (список). "restart": true значит, что скрипт перезапускается при изменении.

    Как скрипт получает настройки: приложение запускает его с переменной среды REMATCH_CONFIG, это путь к JSON-файлу вида {"speed":5,"debug":false}. Файл обновляется при каждом изменении в меню, скрипт может перечитывать его раз в полсекунды. Готовый пример: library/ball-lock-pack/files/balllock_core.py.

  • Обновить скрипт

    Просто загрузи новую версию. У пользователей в каталоге появится метка «Есть обновление», кнопка Обновить в меню сохранит их настройки.

  • Удалить скрипт

    На GitHub: папка library/ → папка скрипта → три точки → Delete directory → Commit. Список обновится сам.

6. Частые вопросы

ВопросОтвет
Надо ли перезапускать игру?Нет. Приложение работает отдельно от игры. Включай и выключай скрипты и открывай оверлей в любой момент, игру перезапускать не нужно.
Надо ли что-то скачивать отдельно?Только Python (один раз) и, для геймпада, драйвер ViGEmBus. Всё остальное приложение ставит само.
Нужен ли у друзей аккаунт GitHub?Нет. Скачивать приложение и скрипты можно без аккаунта.
Скрипты работают, пока приложение открыто?Да. Закроешь приложение, скрипты остановятся. Включённые скрипты запустятся снова при следующем открытии.
Не заблокирует ли игра скрипты?Скрипты читают картинку экрана и эмулируют мышь или геймпад. В онлайн-играх такие вещи могут нарушать правила и приводить к бану, используй на свой риск.

How it works

There is no server and nothing to buy. The library lives in your GitHub repository and the app reads it from there.

WhatWho needs itWhy
Rematch Scripts.exeeveryonethe app itself (catalog, menu, overlay)
Python 3.10+ (python.org, tick Add python.exe to PATH)everyone who runs scriptsthe scripts are written in Python. Installed once
Python libraries (opencv, mss, …)—installed automatically the first time a script is switched on
ViGEmBus driveronly for the "Gamepad" modevirtual gamepad. Installed once
GitHub tokenonly you (the owner)to upload scripts. Nobody else needs it
Only you can upload scriptsThe "Upload" button only appears when the token belongs to the repository owner. Everyone else has no such button and cannot change your repository.

1. Upload the project to GitHub one time

  • Create the repository

    Open github.com/new. Name rematch-scripts, type Public, click Create repository.

  • Upload the files

    Unzip rematch-scripts.zip. On the repository page click uploading an existing file, press Ctrl+A in the project folder and drag everything into the browser (the hidden .github folder must be included; if you can't see it, enable "Show hidden items" in Explorer). Click Commit changes at the bottom. If GitHub complains about the number of files, upload in two batches.

  • Enter your username

    Open config.json → pencil → replace YOUR_GITHUB_USERNAME with your username → Commit changes. Do the same in README.md (the download badge).

  • Let the automation write

    Settings → Actions → General → Workflow permissions → Read and write permissions → Save. Without it the script list won't update.

  • First run of the script index

    Actions tab → Build library index on the left → Run workflow. If it isn't there, change anything in the library folder (for example upload a script through the app, see section 5). The file library/index.json must appear.

  • Polish the page

    Gear next to About: description and topics. Settings → General → Social preview: upload assets/social-preview.png.

    Do not enable "Require a pull request before merging"Uploads from the app write the script straight to main. That rule would block you too. Other people cannot change your repository anyway, they are not collaborators.

2. Build the app (.exe)

  • Start the build

    Actions → Build Windows app → Run workflow. A green check appears in 3–5 minutes.

  • Publish a release

    On the repository home page, right side: Releases → Create a new release → in Choose a tag type v1.0.0 → Create new tag → Publish release. A few minutes later two files are attached:

    FileWhat it is
    Rematch Scripts Setup 1.0.0.exeinstaller, creates a Start menu shortcut
    Rematch Scripts 1.0.0.exeportable: runs immediately, no installation
  • Your own icon

    Replace build/icon.png (1024×1024) and build/icon.ico in the repository, then publish a new release (v1.0.1).

3. How to open the app

  • Download and run

    Repository → Releases → download the .exe → run it. Share the same link with friends.

    Windows SmartScreenThe app isn't signed with a paid certificate. If Windows says "Windows protected your PC", click More info → Run anyway.
  • Install Python

    If you don't have it: python.org/downloads → installer → tick Add python.exe to PATH → Install. The app tells you if Python is missing.

  • Language

    Settings → Interface language (Russian / English). Only the app's labels are translated; script texts stay as written by their authors.

4. How the menu and overlay work

  • Get a script

    All scripts → open one → Download & add to menu. One button: the app downloads the files and puts the script in the menu. The library currently has Rematch Ball Lock Pack (ball tracking).

  • Switch it on

    The Script menu tab: every script has a toggle. The first time, the app installs the Python libraries itself (up to a minute, status "Installing libraries…"). Then the status becomes "Running" with a green dot.

  • Configure

    The gear opens the script's settings: sliders, switches, lists. Changes apply instantly (if a script needs a restart, the app does it for you). Each script can also get its own on/off hotkey: click the field and press the combination. "Reset settings" restores defaults.

  • Overlay on top of the game

    Opens and closes with F10 by default (change it in Settings). It is the same menu in a small window on the right, on top of the game: switch scripts and tweak settings without minimising the game. Close with Esc, the ✕ or the same key. The app must be running (it can be minimised).

Run the game in "Borderless" modeThe overlay and screen capture work when Rematch runs in Borderless windowed mode. In true exclusive fullscreen, windows over the game and screen capture may not work.

5. How you upload new scripts owner only

  • One time: the token

    In the app Settings → Create token on GitHub → Generate token at the bottom → copy the token (ghp_…) → paste it → Save. The Upload tab appears. A token is a password: never share it; it is stored encrypted.

  • Fill in the form

    Title, description, instructions, photos, files (zip and anything else). Click Publish: the script is written straight to the repository and shows up for everyone (after about a minute, press "Refresh").

  • To get a toggle and settings in the menu

    Fill in the two extra fields:

    • Entry file: the name of the main .py file among the uploaded files (e.g. my_script.py).
    • Settings (JSON): the parameters that will appear in the menu. Example:
    [
 {"key":"speed","type":"number","label":{"ru":"Скорость","en":"Speed"},"min":1,"max":10,"step":1,"default":5},
 {"key":"debug","type":"bool","label":{"ru":"Отладка","en":"Debug"},"default":false},
 {"key":"mode","type":"select","label":{"ru":"Режим","en":"Mode"},"default":"a","restart":true,
  "options":[{"value":"a","label":{"ru":"А","en":"A"}},{"value":"b","label":{"ru":"Б","en":"B"}}]}
]

    Types: number (slider), bool (switch), select (list). "restart": true means the script restarts when the value changes.

    How a script receives settings: the app starts it with the environment variable REMATCH_CONFIG, a path to a JSON file like {"speed":5,"debug":false}. The file is rewritten on every change in the menu; a script can re-read it twice a second. Working example: library/ball-lock-pack/files/balllock_core.py.

  • Update a script

    Just upload a new version. Users see "Update available" in the catalog, and Update in menu keeps their settings.

  • Delete a script

    On GitHub: library/ folder → the script's folder → three dots → Delete directory → Commit. The list updates by itself.

6. FAQ

QuestionAnswer
Do I have to restart the game?No. The app runs separately from the game. Switch scripts and open the overlay at any time, no game restart needed.
Do I need to download anything separately?Only Python (once) and, for gamepad mode, the ViGEmBus driver. The app installs everything else itself.
Do friends need a GitHub account?No. Downloading the app and the scripts works without an account.
Do scripts keep running while the app is open?Yes. If you close the app the scripts stop. Scripts that were on start again the next time you open it.
Could the game ban this?The scripts read the screen image and emulate a mouse or gamepad. In online games that can break the rules and lead to a ban; use at your own risk.
